# 需求与验收标准

- 版本：v1（2026-11-01 定稿）
- 来源：grill 访谈 7 轮，全过程见 `03_OutputFiles/reports/grill_report_2026-11-01.md`

---

## 1. 目标

每天一次（12:00），自动整理 AI 行业最新消息，生成一份**一屏能读完**的中文报表供本人阅读。要求**不付费、不申请任何 API 凭证**。

## 2. 硬约束（不可协商）

| # | 约束 | 后果 |
| --- | --- | --- |
| C1 | **不付费**。任何需要订阅、充值、试用到期后收费的方案一律否决 | 否决付费新闻 API、付费 LLM API、付费托管 |
| C2 | **不注册第三方服务、不填 key** | 决定只能用 RSS / 公开网页 / 无凭证接口 |
| C3 | **无后端、无数据库** | 决定为纯静态站 + 定时构建 |
| C4 | **手机和电脑都能读** | 必须有在线链接，同时保留本地可打开副本 |
| C5 | **电脑关机、WorkBuddy 没开，网站仍要更新** | 定时任务必须跑在云端，不能跑在本机 |

## 3. 功能需求

### F1 抓取
- 从多个 RSS 源抓取，源清单见 `04_Project/digest/sources.py`
- 单个源失败不得中断整轮；失败记 warning 并跳过
- 单轮耗时 < 30 秒

### F2 筛选与排序
- 去重：同 URL 去重；标题相似度 > 0.78 视为同一条，保留来源权重高的
- 排序：重要度降序，**不按分类分组**
- 完整版上限 15 条，增量版上限 8 条（v2 起增量版取消，见 §7）

### F3 内容字段
每条必须有：中文标题、原文标题、原文链接、来源、发布时间、分类（六选一）、摘要（可缺）。

### F4 页面
- 移动优先，正文单列，最大宽度 680px
- 前 3 条视觉加重（「今天最值得看」）
- 已读标记：点过的条目变淡并折叠摘要，状态存 `localStorage`
- 期次切换：能翻历史
- **降级**：摘要缺失时显示原文标题，页面不得出现空白条目

### F5 时间
- 12:00 完整版，18:00 增量版（北京时间）（v2 起只保留 12:00）
- 云端 cron + 15 分钟延迟容忍

## 4. 非功能需求

| # | 要求 |
| --- | --- |
| N1 | 手机 4G 打开 < 3 秒 |
| N2 | 首屏 HTML+CSS+JS 总量 < 120 KB（不含嵌入的历史数据） |
| N3 | 全部代码仅用 Python 标准库，接手者无需 `pip install` |
| N4 | 仓库内无任何密钥；无后端故无攻击面 |
| N5 | 任何一环故障都不得导致白屏 |

## 5. 验收标准

标注以 **2026-11-01 14:30（北京时间）** 的实测为准。**没跑过的就不打勾**——「未跑就声称通过」本身是违规。

| # | 标准 | 状态 |
| --- | --- | --- |
| 1 | 手机打开链接，3 秒内看到 15 条，无横向溢出 | ✅ 本地 http 起服务、真 390px iframe 内量测：`clientWidth=375 scrollWidth=375 溢出元素=0 条目=15`（375 是去掉滚动条后的内容宽度，比真机 374 还窄一点）。证据：`03_OutputFiles/work/p390_1430.png` |
| 2 | 每条都有标题、来源、时间、分类、可点原文链接 | ✅ 15/15 齐全 |
| 3 | 已读状态刷新后保留 | ⚠️ 代码成立（localStorage + 渲染加 `read` 类），未真机复验 |
| 4 | 能翻看历史期次 | ⚠️ 目前只有 1 期，无从验证；期次按钮数已与内嵌期次数统一（都读 `data.js` 的 `embedLimit`） |
| 5 | **删空 `content/summaries/` 后重新构建，页面依然完整可读** | ✅ 实测通过，`has_ai_summary=false`，标题回落原文 |
| 6 | 电脑关机一整天后，网站仍有当天那一期 | ❌ **未验证**。上线至今没有一条 `schedule` 触发的运行记录，首次排期在 11-02 04:00 UTC |
| 7 | `git grep` 无密钥命中 | ✅ 仅命中文档里的说明文字 |
| 8 | 克隆到新机器，只装 Python 即可跑出完整站点 | ✅ 纯净环境 `--rerender` 通过，零第三方依赖 |

仍未通过的第 6 条是唯一真正的空白：**云端 cron 还没按点跑过一次**。明天中午看页面就能确认。

## 6. 明确不做

- 不做登录、不做多用户
- 不做收藏 / 稍后读（会退化成第二个待办清单）
- 不做全文抓取与翻译（成本高、失真大）
- 不接付费 API，不接大模型 API
- 不做推送通知（微信/邮件）
